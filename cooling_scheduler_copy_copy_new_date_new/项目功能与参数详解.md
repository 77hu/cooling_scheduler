## 四、滚动机制（--once / --live 共用，run_once 七步）

1. **天气窗口**（失败→缓存→no_data_hold 保持上步动作，fail-operational）
2. **电价三级回退**（当日 DB → 今日价 → 默认 0.23/1.11）+ 跨午夜逐时拼接
3. **DP 重解**（实测初值 + 显式锁存 + start_hour 钟表时刻映射）
4. **冻结承诺**（首步与上轮承诺冲突 → 维持承诺，防启停抖动）
5. **安全覆写**（≥38°C 强开 / ≤18°C 强关，永远压过冻结）
6. **登记新承诺**（未来 commit_horizon_h 小时）+ 清过期
7. **锁存传递**（用模型重推一步算出执行后的 charge_latch，传给下一轮）

优先级链：**安全覆写 > 冻结承诺 > DP 原始决策**。返回值同时含 `raw_first_action`（DP 原始）与 `first_action`（实际执行），全程可审计。

## 五、--live 模式细节（2026-08-25 新增）

- 三类数据：电解液温度（实测序列做每轮锚点）+ Open-Meteo 真预报 + DB 真电价
- 每轮：当前温度=数据[h] → run_once → 承诺动作 → `_settle_hour` 用物理模型结算本小时成本并推进 SoC/锁存（下一轮温度由实测数据覆盖，**温度不靠模型外推**）
- 真·实时模式（`--realtime`）：每整点前 `--lead-minutes`（默认 5）分钟醒来算好指令，给 PLC 留提前量；控制格仍对齐整点
- 产物：`output/live_rolling_{日期}.csv`（11 列逐时记录）+ 5 张图（温度/计划甘特/电价/电费/SoC）+ 复合总览图
- ⚠️ **当前状态**：`load_temperature_data()` 是硬编码 24 值数组（28.0→33.1→29.0），`--temp-file` 参数被 argparse 强制要求但**尚未真正接入**（文件读取行被注释）
- ✅ 已验证运行：2026-08-25 18:00 起 24 轮，累计电费 13.12 元，跨午夜电价正常切换（8-25 用 DB 真实价 0.5885/0.4686，8-26 用默认 0.23/1.11），求解 24s/轮

## 六、物理模型核心（参数锚点）

**热网络**：电解液主节点（C_th=60.48 MJ/K）+ 电堆节点（1.143 MJ/K，UA=12.03 W/K）+ 室内空气代数节点；集装箱总传热 UA=90 W/K（full 保温）→ 温度时间常数 ≈7.8 天。
能量平衡：`T_ely' = T_ely + (Q_gen + Q_wall − Q_cool + Q_heat)·dt/C_th`

**电化学**：OCV = 55 + 1.5·ln(SoC/(1−SoC)) V；Arrhenius 内阻（Ea_R=2500）；充电可逆熵吸热（中 SoC 净吸热 ~3 kW）、放电产热 ~41 kW；SoC 积分（常数 55V 计量）；shunt 损耗 450·SoC W。

**冷却设备**（tech_id 二选一）：
- 板式（默认）：Q = min(544×(T−7)×0.9, 14000) W；COP = max(2.9−0.08·ΔT_amb, 1.5)；待机冷却免主泵
- EKES 直冷：15 kW×scale，≤22°C 停机，COP = max(3.65−0.05·ΔT_amb, 2.0)；冷却时主泵必须额定

**充放电状态机**：充电 10:00–17:00（止点硬编码热模型）、放电 18:00–次日 6:00；SoC 窗 0.10–0.90；charge_latch 撞限置位、出充电窗清除。

### 7.2 热系统
电解液 14000L×1.35×3200 → C_th 60.48 MJ/K；保温 full U=0.5 / partial 2.07 W/m²K（外壳 60 m²）；sol-air α=0.6、h_ext=35、日出 5.75 日落 19.17；通风残差因子 0.0991、风扇 150 W、触发温差 3.0/1.0 K。

### 7.3 TOU 电价（price_list=[谷,峰] 默认 [0.23, 1.11]）
平 = 0.47×峰 + 0.53×谷 = 0.6436；尖峰 = 峰×1.25 = 1.3875（**定义但从不生效**）。
时段：谷 00–08 / 平 08–10 / 峰 10–12 / 平 12–14 / 峰 14–19 / 平 19–24（共 7 个峰时）。

### 7.4 DP 优化
温度网格 20–40°C/0.25（81 格，config 可配）；SoC 网格 0–1/0.05（21 格，**优化器内硬编码**）；舒适区 25–35°C（config）；启停惩罚 3.0 元/次（config）；越限惩罚 10×(T−35)² / 5×(25−T)²（硬编码）；终值 SoC 软限 20×越(0.15/0.85)²（硬编码）；目标函数只计冷却电费。
死参数：`run_penalty`(2.5 已注释)、`peak_price_threshold`(1.0 无人读)。

### 7.5 滚动调度与安全（RunContext）
commit_horizon_h=1（0~2）；T_emergency_high=38°C；T_safe_low=18°C；horizon_h=24；数据源可注入（闭环仿真用）。

### 7.6 数据源
Open-Meteo（深圳 22.504639, 114.06105，滚动链路 forecast_days=2 按时间戳切片，缓存回退）；PostgreSQL `47.107.118.226:5432/energy` 表 `electricity_price_v3`（⚠️ 密码明文在 config.DB_CONFIG L57）。
